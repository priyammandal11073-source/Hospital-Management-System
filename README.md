# Hospital Management System

A full-stack Hospital Management System built as a solo college project with React, Express, Node.js, and MongoDB. It will manage staff authentication, patients, doctors, appointments, billing, and basic reports.

## Project structure

```text
Hospital-Management-System/
├── client/                 # React frontend (Vite + Tailwind CSS)
│   └── src/
│       ├── components/     # Reusable UI pieces
│       ├── context/        # Shared state, such as authentication
│       ├── pages/          # Route-level screens
│       └── services/       # API request functions
└── server/                 # Express + MongoDB backend
    ├── config/             # Database connection
    ├── controllers/        # Route logic
    ├── middleware/         # Authentication and error handling
    ├── models/             # Mongoose schemas
    └── routes/             # API endpoint definitions
```

## Run locally

1. Install the server packages:

   ```bash
   cd server
   npm install
   Copy-Item .env.example .env
   npm run dev
   ```

2. In a second terminal, install and run the Vite React client:

   ```bash
   cd client
   npm install
   Copy-Item .env.example .env
   npm run dev
   ```

`client/package.json` and the Vite files are the same setup generated by `npm create vite@latest client -- --template react`, with Tailwind CSS and React Router added. Tailwind is configured through `tailwind.config.js`, `postcss.config.js`, and `src/index.css`.

## Environment variables

Copy `server/.env.example` to `server/.env`, then set a valid `MONGO_URI` and a long, private `JWT_SECRET`. Never commit `.env`: the project `.gitignore` excludes it.
